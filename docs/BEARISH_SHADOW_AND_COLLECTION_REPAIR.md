## Debugging procedure

1. Read `state/latest.json` and the `strategy_evaluation_audit.json` / `bearish_selection_diagnostics.json` for the latest evaluated directions, true and false gates, and contract economics.
2. Read `state/contract_coverage_latest.json` for *which* right and delta book lacks shortlisted and protective leg coverage; check complete instrument pagination and original quote timestamp before adding data.
3. If `state/second_quote_request.json` exists, issue a connector call immediately for **those exact listed leg IDs** and republish genuinely newer provider data. If an older batch is returned, mark the candidate `ORDER_UNFILLED`, never restamp it. Do not rely on watchdog ticks to fetch quotes.
4. Check `state/paper_ledger.json` for baseline fills, `state/bearish_call_shadow_ledger.json` for bearer-only matched paper shadow fills, and `state/bwb_paper_ledger.json` / `state/sniper_paper_ledger.json` independently.
5. If direction is `UNCONFIRMED`, explain the underlying close and VWAP breakdown/retest conditions that failed. Do not force a direction or change entry hours in a diagnostic run.
